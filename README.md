
# AutoWorld — Car Collection

## 1. Project Description

AutoWorld is a website dedicated to premium automobiles and the automotive industry. The website presents popular car brands, modern vehicles, and information about the world of luxury and sports cars.

The main purpose of the project is to create a modern, informative, and responsive website for automobile enthusiasts.

## 2. Target Audience

The website is intended for:
- Car enthusiasts.
- People interested in premium and sports cars.
- Users who want to learn about famous automotive brands.
- Visitors interested in modern automobile design and technology.

## 3. Functional Requirements

The website must provide the following functionality:
- Display the homepage with a main banner.
- Provide navigation between website sections.
- Display a collection of featured automobiles.
- Present information about popular automotive brands.
- Include an About section describing the project.
- Provide contact information.
- Display correctly on desktop, tablet, and mobile devices.

## 4. Website Structure

The website consists of the following sections:

- **Home** — main page with a banner and introductory information.
- **Cars** — collection of featured automobiles.
- **Brands** — list of popular automotive brands.
- **About** — information about the AutoWorld project.
- **Contact** — contact information.

## 5. Design Requirements

The website uses a modern automotive-inspired design.

- **Primary background:** dark (#111111).
- **Secondary background:** black (#080808).
- **Accent color:** red (#e63946).
- **Text color:** white (#ffffff).
- **Font:** Arial, sans-serif.
- **Layout:** CSS Flexbox and CSS Grid.
- **Visual style:** modern, minimalistic, and responsive.

## 6. Technical Requirements

The project is developed using:
- HTML5 — website structure and content.
- CSS3 — layout, styling, and responsive design.
- Git and GitHub — source code management.
- GitHub Pages — website publication.

The website uses CSS media queries to adapt its layout to different screen sizes.

Supported browsers:
- Google Chrome.
- Mozilla Firefox.
- Microsoft Edge.
